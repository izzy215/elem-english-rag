## 3. 근본 원인

`backend/tutor.py`의 `_is_typo(a, b)` 함수는 두 단어가 "진짜 철자 실수"인지 판정한다. 아래 4개 예외 조건에 걸리면 철자로 보지 않는데, `who`/`whose`는 **어디에도 안 걸린다**:

| 예외 조건 | who/whose 해당 여부 |
|---|---|
| `_func_words()`(문법 기능어 목록)에 있음 | ❌ 없음 |
| `_CORE_ADD`(핵심 기능어: am/is/are/a/an 등)에 있음 | ❌ 없음 — **이게 빠진 부분** |
| `_IRREGULAR_BASE`(불규칙 변화쌍: go/went 등)에 있음 | ❌ 없음 |
| errors.jsonl에서 학습된 교체쌍(`swap`)에 있음 | ❌ 없음 |

4개 다 안 걸리니 마지막 단계인 **순수 편집거리(Levenshtein distance)**로만 판정한다:

```python
_edit_distance("who", "whose") = 2
threshold(5글자 단어) = 2
2 <= 2  →  True (철자 실수로 오판)
```

`is`/`are`, `a`/`an` 같은 문법 기능어 교체는 이미 `_CORE_ADD`에 등록돼서 이 함정을 피하는데, **`who`(주격 의문사)/`whose`(소유격 의문사)는 등록이 안 돼 있어서** 단순히 글자 수 차이(2글자)만으로 철자 오타 취급된 것이다. 실제로는 문법적으로 다른 단어(격이 다름)이지, 철자 오타가 아니다.
