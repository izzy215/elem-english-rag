관리자 · 기획 포인트

  1. 화면 하나. 로그인·선생님 관리·승인 워크플로우 없음. 데이터 상태 · 정확도 · 등록 세 패널이 전부.
  2. 정확도 그래프가 발표의 핵심 숫자. 청킹 전략 A/B/C를 같은 평가셋으로 비교한 결과. 62 → 84가 "개선했다"의 증거.
  3. 검수 경고는 판단 보조. RAG가 "범위 밖 단어"와 "유사 문장"만 알려주고, 등록 여부는 사람이 정함.
확인 필요 ① 등록한 문장은 어디로 가나? (a) 골든 데이터에 바로 합침 (b) "대기" 상태로 두고 데이터팀이 검토 후 합침. 기본안: (b). 저장 API 소유자도 미정.
확인 필요 ② 정확도 그래프를 학생 앱에도 보여줄지 (아니오가 기본). 발표에서만 쓰면 관리자 화면으로 충분.
결정됨 관리자 화면은 △ → 1차에 포함. 검수 경고는 한 줄 이상 확장하지 않음. (기획서 v0.2)
