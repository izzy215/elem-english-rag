# 설계 미결 목록 (design-backlog) v0.1

작성 2026-09-04 · 팀장 · 상위 문서: [PRD](PRD.md)
PRD는 화면·API·데이터 형식을 정한 "계약"이고, **그 안에서 어떻게 동작하는지**는 아직 비어 있다.
이 문서는 비어 있는 부분의 목록이다. 각 항목은 담당별 설계서에서 결정하고, 정해지면 여기서 ✓ 처리한다.

설계서 구성:
```
docs/
├─ PRD.md               계약 (변경 시 셋 합의)
├─ design-backlog.md    이 문서 — 무엇이 비어 있고 누가 언제 정하나
├─ design-screens.md    팀장: 화면 상태·예외·문구, 학습 완료 기준, 학생 전환      ← 초안 있음
├─ design-quiz.md       팀장: 문제 생성 규칙, 오답 반영, 오답 설명, 캐싱           ← 초안 있음
├─ design-rag.md        RAG 담당: 청킹 실험, 평가 정의, Chroma 구성, 검수 임계값     (작성 예정)
├─ design-audio.md      TTS 담당: TTS 사전 생성, STT 유사도, 예외 처리              (작성 예정)
└─ design-data.md       RAG 담당(데이터팀 창구): 골든 검증, 교체 절차, 소스 등록 이후 (작성 예정)
```
각 설계서는 A4 한 장, 항목마다 **결정 / 근거 / 미정** 세 칸.
