초등 영어학습 · RAG 맞춤 복습

v0.2 초안 · 팀 회의용 작성 2026-09-04 · 팀장 다음 문서: PRD (이 문서로 범위 합의 후)

1한 줄 정의

초등학생이 Level·Unit을 골라 단어·문장을 학습하고, AI가 낸 문제를 풀면 틀린 내용을 기록해 두었다가 RAG가 교재에서 근거를 찾아 그 학생에게 맞는 문제와 설명을 다시 만들어 주는 학습 서비스.

학습→오답 기록→RAG 교재 검색→맞춤 문제 · 오답 설명→다시 학습

2왜 만드는가

  • 수업 요건 — Gemini API · RAG · 프롬프트 엔지니어링 · (선택) BigQuery / Vertex AI
  • 팀 목표 — RAG를 중심에 두고, "검색 정확도를 숫자로 개선했다"를 발표의 핵심으로 삼는다
  • 차별점 — 문제은행이 아니라 교재 근거 + 학생 오답 이력으로 문제가 학생마다 달라진다

결정 · 2026-09-04
RAG의 주인공은 학습용(학생 화면 · 데모 · 정확도 숫자). 검수용은 같은 엔진의 부가 입구로, 등록 시 경고 한 줄 이상 확장하지 않는다.
변경 · RAG 검수 경고 · 듣기(TTS) · 말하기 평가를 △/2차에서 1차(○)로 승격. 말하기 평가는 유사도 채점까지만.

5화면 목록

  1. 시작 — 학생 이름 선택 → Level 선택
  2. Unit 목록 — 해당 Level의 Unit 카드
  3. 학습 — 단어 카드(뜻 · 예문 · 듣기) → 문장 카드(듣기 · 따라 말하기 → 점수)
  4. 문제 풀기 — AI 문제 3~5개, 즉시 채점
  5. 오답 설명 — 틀린 문제별 설명 + "교재 N쪽" 근거, [다시 풀기]
  6. 정확도 대시보드 (관리자, △) — 평가셋 기준 검색 정확도, 개선 전후 비교. 소스 등록 폼에는 RAG 검수 경고 한 줄만

7데이터 — 골든 데이터셋

담당: 골든 데이터셋 팀 · 상세 기획서 별도 작성 예정. 이 문서에서는 우리 서비스가 받을 형식(인터페이스)만 정한다. 형식은 데이터팀과 협의 후 확정.
파일 (안)내용서비스에서 쓰는 곳
words.csvlevel, unit, word, meaning, example, source_page단어 학습, 문제 생성
sentences.csvlevel, unit, sentence, meaning, source_page문장 학습, 문제 생성
chunks.jsonlid, text, level, unit, source_pageRAG 검색 대상 (04_rag_chunks)
eval.csvquestion, expected_chunk_id 또는 expected_answer검색 정확도 측정 (05_evaluation)

데이터팀에 요청할 사항 (작성 예정)

  • 원본 교재 후보와 저작권 확인 (교육부 기본 어휘 목록 등)
  • Level · Unit 정의 (몇 학년 = Level 몇, Unit당 단어 수)
  • 1차 납품 범위: 데모용 Unit 2~3개, 단어 50~100개면 충분
  • 평가셋 최소 30문항
  • 납품 일정: 1주차 말 (RAG 개발이 2주차에 시작되므로)

데이터가 늦어질 경우: 개발팀이 임시 샘플 데이터(단어 20개)로 먼저 개발하고 나중에 교체한다.

10성공 기준

데모 60초

  • Level → Unit → 단어 학습
  • 문제 3개 → 1개 틀림
  • 근거 있는 설명 ("교재 12쪽")
  • 다시 풀기 → 틀린 단어 우선 출제, 학생 B와 다름

숫자

  • 평가셋 30문항 기준 검색 정확도 (상위 3개 안에 정답 포함) 80% 이상
  • 개선 전후 비교 그래프 1장

비용

  • 무료 티어 내 운영
  • TTS 캐시 · 임베딩 1회 생성

11리스크

리스크대응
골든 데이터 납품 지연임시 샘플 데이터로 개발 선행, 형식만 먼저 합의
Gemini 응답 30초문제는 5개 이하, "생각 중" 표시, 가능하면 경량 모델
화면 작업이 AI 시간을 잠식화면 5개 고정, 기존 목업 CSS 재사용
검색 정확도가 안 오름청킹 단위(단어별/문장별) 비교, 키워드 검색 병행(하이브리드)
말하기 평가(STT) 품질원문 유사도 채점으로 한정. 3주차 초까지 안 되면 "녹음 → 텍스트 보여주고 자기 채점"으로 축소
