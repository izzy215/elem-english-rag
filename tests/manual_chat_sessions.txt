# 챗봇(/api/ask) 수동 테스트용 — 세션 20개 x 4~5문항 = 100문항
# 한 세션 = 같은 학생이 이어서 묻는 대화(같은 student id로 순서대로 입력).
# 태그: [단어] 단어 조회 · [문법] 규칙 질문 · [정오] 문장 맞는지 확인 · [이어가기] 직전 답 이어받기
#       [오답노트] 오답노트 화면 질문 · [인사] 고정답 · [오프토픽] 잡담(거절 확인용) · [오타] 맞춤법/오타 섞은 질문
# 문장 뒤 "  # 메모"는 왜 넣었는지 설명.
